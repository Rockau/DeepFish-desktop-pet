# 鱼眼：陪玩陪看

让桌面上的大肥鱼陪你打游戏、看番、刷视频、看网页：她会看你最前面的窗口，看懂画面在发生什么，到了精彩、好笑、翻车的地方自己吐槽一两句；剧情虐的时候安静陪着，打得激烈时只喊大事，你在干活、聊天时基本不出声。

> 这是 `Fisheye` 分支才有的功能，`main` 分支的大肥鱼插件没有。

> ⚠️ **对电脑配置要求较高。** 它要在你自己的显卡上跑一个视觉模型，所以需要 **NVIDIA 独立显卡**，显存实打实占用约 8GB；一边打游戏一边开，还会和游戏抢显存、抢 CPU。显卡弱、显存小、只有核显或 AMD 显卡的电脑，不建议装。详见下面的[「配置要求」](#配置要求)。

## 怎么做到的

| 步骤 | 做法 | 在哪 |
|---|---|---|
| 看 | 每 0.5 秒看一眼最前面的窗口有没有变（会先把大肥鱼自己盖掉）；变了或者隔久了，截一帧给**本机显卡上的视觉模型** Qwen3-VL-8B（llama.cpp 跑），它判断你在干什么、画面里发生了什么、气氛、值不值得说、你是不是正忙 | 本机，截图不落盘、不上传 |
| 读字幕 | 视觉模型先抄下当前那句字幕，再用 RapidOCR 找到字幕在画面里的位置，之后每秒只读那一条 | 本机 |
| 听 | 借插件跳舞用的声音探针，知道电脑在不在出声、是哪个程序、安静了多久（只听音量，听不懂内容） | 本机 |
| 分寸 | 按场景（打游戏、看剧、刷视频、看网页、干活、聊天）定门槛和冷却；看剧等对白的空档再开口；没人理她就慢慢少说，摸她一下又热络起来 | 本机 |
| 想台词 | 值得说的时候，把**文字描述**（不是截图）交给 DeepSeek，按 `人设.md` 写一两句，带〔〕动作 | DeepSeek API |
| 说 | 通过插件的本机网页接口让她说出来 | 本机 |

每 3 分钟会把最近的画面记录整理成一段“前情”，所以她跟得上剧情和战局。

## 配置要求

先说结论：**这套功能吃显卡，不是随便一台电脑都带得动。** 看画面的视觉模型是跑在你自己显卡上的（不上传截图的代价就是算力得自己出）。

| 项目 | 最低（能跑，但会很吃紧） | 推荐（能边玩边开） | 说明 |
|---|---|---|---|
| 显卡 | NVIDIA，显存 12GB | NVIDIA，显存 16GB 以上（RTX 4070 Ti Super / 4080 / 4090 这一档） | 视觉模型约占 **8GB 显存**；没有 NVIDIA 显卡不能用（AMD、Intel 核显都不行） |
| 内存 | 16GB | 32GB | 加载模型和截图处理要用一点，游戏本身也吃内存 |
| CPU | 6 核以上 | 8 核以上 | 读字幕（OCR）跑在 CPU 上，每秒一次 |
| 硬盘 | 空闲 8GB | 空闲 10GB 以上，最好放固态 | 模型约 6GB，llama.cpp 约 0.8GB，Python 环境约 0.3GB，加载模型时固态会快很多 |
| 系统 | 64 位 Windows 10 / 11 | 同左 | 显卡驱动要新，装脚本会检查 |

**我自己的实测环境**：i9-14900K、32GB 内存、RTX 4090（24GB 显存），4K 屏。在这台上：
- 视觉模型每看一张画面约 **1.5 秒**，占约 **7.7GB 显存**；
- 读一次字幕约 **0.6～1.1 秒**（CPU，4K 屏截图）；
- 看视频、玩一般的游戏毫无压力。

**需要提前知道的事**
- **边玩大型游戏边开会挤**：现在的 3A 大作自己就能吃 12～16GB 显存，再加上视觉模型的 8GB，显存不够的卡会掉帧、卡顿，甚至游戏崩溃。显存 24GB 的卡才比较稳；显存小的话，建议只在看视频、玩小游戏时开，或者玩大作时先在托盘里把「陪玩陪看」关掉（关掉后视觉模型会退出，显存立刻还回来）。
- **显存不到 10GB** 的卡：安装脚本会给出警告，不建议继续。
- **看画面有延迟**：显卡越弱，她“看到”的画面越晚，吐槽也就越滞后。
- **没有合适的显卡怎么办**：目前没有支持的替代办法。想省显存可以在 `config.json` 里把 `vision_model` 换成更小的视觉模型（比如 Qwen3-VL 的 4B 版），但**我没测过**，效果和稳定性不保证。
- 上面“最低”一档的数字是按模型占用估的，**只在 4090 上实测过**；低配机器没有实际跑过，能不能带得动以你自己的试用为准。

**其他要装好的**
- Python 3.10 以上（没有的话：`winget install Python.Python.3.12`）
- DeepSeek 的 API key（不填也能跑，那样她只看不说）
- 大肥鱼插件本身已经装好（见仓库根目录的 README）

## 安装

1. 在插件文件夹里重新运行一次 `setup.ps1`（插件根目录那个），把托盘控制台编译成带「陪玩陪看」的版本。
2. 在 `fisheye` 文件夹里运行：
   ```
   powershell -ExecutionPolicy Bypass -File setup.ps1
   ```
   它会建 Python 环境、下载 llama.cpp（按你的驱动选 CUDA 13 或 12 的版本，从 GitHub 下）和视觉模型（约 6.2GB，先从魔搭下，不行再从 Hugging Face 下），都按 SHA-256 校验。装好的会跳过，中途断了再运行一次就行。
3. 把 DeepSeek 的 API key 填进 `fisheye\config.json` 的 `deepseek_api_key`；也可以不填这里，填在插件 `settings.json` 的 `LlmApiKey` 里，两边共用。**key 只放在本机，别发给别人、别提交进仓库**（`.gitignore` 已经排除了 `config.json`）。

## 怎么用

本机已有支持图像输入的 Ollama 模型时，可将 `vision_url` 指向本机 Ollama，并在 `ollama_model` 填模型名（例如 `qwen3.5:9b`）。鱼眼用同一个本机模型看画面、写评论和记前情。复用现有 Ollama 的安装只需要 `requirements.txt` 中的 Python 依赖。

- 点任务栏右下角的小鲸鱼 → 更多设置 → 「陪玩陪看」点开 → 打开「开启陪玩陪看」。加载视觉模型要几秒，栏里会写她正在看什么、刚说了什么。
- 「话多话少」滑块随时拖，一秒内生效。
- 关掉开关，她说一声再停，视觉模型一起关掉，显存还回来。大肥鱼退场后鱼眼一分钟内也会自己退出。
- 快捷键：`Ctrl+Alt+F9` 暂停/继续，`Ctrl+Alt+F10` 让她现在就说一句。
- 想看每一步在干什么（调试）：双击 `启动鱼眼.bat`，会开一个窗口显示过程。托盘和 bat 只会开一个。
- 开着鱼眼时会先关掉插件的「别的程序全屏时藏起来」，关掉鱼眼时改回去。打游戏用“无边框窗口”最好：独占全屏的游戏会盖住大肥鱼，有的还截不到画面。

## 她看哪个窗口

只看你**最前面、正在用**的那个窗口（窗口太小时看它所在的整块屏幕）。后面被挡住的看不到。微信、QQ、钉钉、飞书、密码管理器这类程序在最前面时完全不看（名单在 `config.json` 的 `ignore_apps`）。

## 能调的（config.json，改完重开鱼眼生效）

| 项 | 说明 |
|---|---|
| `chattiness` | 话量的初始值，之后以托盘滑块为准 |
| `ignore_apps` | 这些程序在最前面时不看 |
| `dry_run` | `true` 就只看不说 |
| `unhide_in_fullscreen` | 开着鱼眼时先关掉“全屏时藏起来” |
| `deepseek_model` | 写台词用的模型，默认 `deepseek-chat` |
| `deepseek_base_url` | 换成别的 OpenAI 兼容接口也行 |

她的口气在 `人设.md`，可以直接改（默认管你叫“老大”，和插件自带台词一致）。

## 隐私

- 截图只给本机显卡上的视觉模型看，不落盘、不上传。
- 发给 DeepSeek 的只有文字：画面的一句话描述、字幕、窗口标题。像密钥、口令的长串会先打码成“[已隐藏]”；你在干活、聊天、或者画面是隐私内容时，这些记录不会发出去。
- 运行记录在 `fisheye\logs\`，随时可以删。

## 第三方

运行时下载、不随仓库分发：[llama.cpp](https://github.com/ggml-org/llama.cpp)（MIT）、[Qwen3-VL-8B-Instruct-GGUF](https://modelscope.cn/models/Qwen/Qwen3-VL-8B-Instruct-GGUF)（Apache-2.0）、[RapidOCR](https://github.com/RapidAI/RapidOCR)（Apache-2.0）、mss、Pillow、NumPy、requests、onnxruntime。

“实时感知陪玩”的思路参考了 [Shinsekai](https://github.com/RachelForster/Shinsekai) 的介绍（按场景调节发言节奏、OCR 读字幕、本地视觉模型），代码是重新写的，没有使用它的源码。
